# Bundled data

aerospace-v1.zip is the actual version 1 public synthetic aerospace archive downloaded for the capstone. The app verifies its SHA-256 before first import:
844ba09645c33a09dbb2be28b9a8f560815ef38929ddcc818b33ecc3df2d8168

Source:
https://www.kaggle.com/datasets/robertocarlost/aerospace-supply-chain-performance-and-forecasting

It contains 280,800 weekly history rows, 300 parts, 29,666 purchase orders and 368 quality incidents. Six sites and 156 weeks create 1,800 site-part series. The publisher describes this dataset as synthetic. Currency is unspecified.

demonstration.zip is independent synthetic test data retained from v1. It is used only by explicit demo fixtures, not the normal first-run workspace.
